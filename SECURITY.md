# Security policy

CV Studio is a local desktop app: it has no server, no account and makes no network connections.
It does read files you choose (photo, backup files) and writes the PDF/Word files you ask for.

## Supported versions
The latest 1.0.x release.

## Reporting a vulnerability
Please **do not** open a public issue for a security problem. Use GitHub's private reporting instead:
**Security tab → "Report a vulnerability"** (the repository owner must have private vulnerability reporting enabled).
Include what you found, how to reproduce it, and the version. Do not include real personal data.
