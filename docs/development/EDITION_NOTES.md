# CV Studio 1.0.0 — Edition notes

Standard edition: all 30 templates are available with no Premium interface or purchase flow.

Both editions include the same template-selection workflow: finish entering CV information, open Templates, click a design to preview it, and press **USE THIS TEMPLATE** on its card. The selection is saved and the app returns to the preview/export screen.

No automatic updater has been added. Existing CV data structures and core document-generation logic have been preserved.
